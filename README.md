# WinThrow

An Autoit script to throw windows around for purposes of wish fulfillment and fun.
You can terminate the script by hitting F2, or using the tray icon.

## Requirements

- Compiled release (.exe) runs without AutoIt.
- To build from source: AutoIt 3.3.18.0 or later from https://www.autoitscript.com/site/autoit/downloads/
